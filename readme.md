This repository is created for Part 4 and Part 5 of JSAT2
project requirements for Part 5 - MovieList
Requirement #	Requirement Details
1	The MovieList class must use and maintain a JavaScript array of Movie objects
2	The UI must include an Add Movie section with inputs for Movie ID, Title, Year, Rating and a submit button for adding new movies into the MovieList array. 
3	The UI must include a display Movie List section with a list view and a Refresh button that reloads current movie list from the MovieList class.
4	The UI must include a Search function to find movies via ID and/or title and display the search results in the list.
5	The UI must include a Sort Movie section with buttons; A-Z{title}, Z-A{title} and best movies {Rating high-low} and display the sorted list. 
6	The UI is to be styled with HTML and CSS with a consistent theme for better user experience.
7	The UI and JavaScript functions must be tested to ensure correct behaviour (data updates, searches, sorting, list rendering)
8	Wireframe prototype must be created before building the full UI.
9	A web-based UI must use HTML, CSS and JavaScript, following a workflow steps provided; requirements > prototype > UI > Testing > Documentation > client sign off.
